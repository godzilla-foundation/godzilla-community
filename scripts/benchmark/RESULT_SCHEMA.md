# Benchmark Result Schema

This document defines the current v1 output schemas for `scripts/benchmark`.

## Joined Journal Latency CSV

Generated by:

```bash
python3 analysis/summarize_latency_journal.py --out-dir analysis/output
```

Default path:

```text
analysis/output/joined_latency_journal.csv
```

Columns:

| Column | Type | Description |
| --- | --- | --- |
| `run_id` | string | Run label. Current journal analyzer uses `journal`. |
| `system` | string | System label. Current value is `godzilla`. |
| `depth_session_id` | integer | Kungfu journal session id for mock MD. |
| `strategy_session_id` | integer | Kungfu journal session id for benchmark strategy. |
| `td_session_id` | integer | Kungfu journal session id for mock TD. |
| `depth_gen_time_ns` | integer | Journal `gen_time` for the matched `Depth` frame. |
| `depth_trigger_time_ns` | integer | Journal `trigger_time` for the matched `Depth` frame. Often `0` for MD-originated frames. |
| `order_input_gen_time_ns` | integer | Journal `gen_time` for the matched `OrderInput` frame. |
| `order_input_trigger_time_ns` | integer | Journal `trigger_time` for the matched `OrderInput` frame. |
| `order_gen_time_ns` | integer | Journal `gen_time` for the matched `Order` report frame. |
| `order_trigger_time_ns` | integer | Journal `trigger_time` for the matched `Order` report frame. |
| `depth_event_id` | integer | `Depth.data_time` from native mock MD. |
| `join_depth_method` | string | Depth matching method: `price_side`, `time`, or `unmatched`. |
| `join_order_method` | string | Order report matching method: `order_id`, `time`, or `unmatched`. |
| `symbol` | string | Trading symbol, e.g. `BTC-USDT`. |
| `side` | string | Order side, `BUY` or `SELL`. |
| `price` | float | Order price. |
| `qty` | float | Order quantity. |
| `order_id` | integer | Kungfu order id from `OrderInput.order_id`. |
| `client_order_id` | string | Optional client order id. Currently empty in the native journal path. |
| `md_to_order_input_ns` | integer | `order_input_gen_time_ns - depth_gen_time_ns`. |
| `order_report_ns` | integer | `order_gen_time_ns - order_input_gen_time_ns`. |
| `total_tick_to_trade_ns` | integer | `order_gen_time_ns - depth_gen_time_ns`. |

## Summary JSON

Generated at:

```text
analysis/output/summary_journal.json
```

Top-level keys:

| Key | Type | Description |
| --- | --- | --- |
| `metadata` | object | Run/session/join metadata. |
| `metrics` | object | Percentile summaries by latency metric. |

`metadata` fields:

| Field | Type | Description |
| --- | --- | --- |
| `home` | string | Kungfu home directory used by the analyzer. |
| `session_ids` | object | Selected MD, strategy, and TD session ids. |
| `input_rows` | object | Raw rows read from each session: `depth`, `order_input`, `order`. |
| `max_messages` | integer | Maximum frames read per session. |
| `join_counts` | object | Counts grouped by matching method. |
| `joined_rows_raw` | integer | Joined rows before `skip_first`. |
| `joined_rows` | integer | Joined rows after `skip_first`. |
| `skip_first` | integer | Number of joined rows discarded before summary. |
| `price_epsilon` | float | Price tolerance for `price_side` matching. |
| `time_basis` | string | Human-readable timestamp basis description. |

Each metric under `metrics` has:

| Field | Type | Description |
| --- | --- | --- |
| `count` | integer | Number of valid values. |
| `min_ns` | integer | Minimum latency. |
| `max_ns` | integer | Maximum latency. |
| `mean_ns` | float | Arithmetic mean. Not recommended as the primary headline metric. |
| `p50_ns` | float | 50th percentile. |
| `p90_ns` | float | 90th percentile. |
| `p99_ns` | float | 99th percentile. |
| `p99_9_ns` | float | 99.9th percentile. |

Current metrics:

- `md_to_order_input_ns`
- `order_report_ns`
- `total_tick_to_trade_ns`

## Raw Journal CSVs

The analyzer also writes raw flattened journal rows under:

```text
analysis/output/journal_raw/
```

Files:

| File | Message type |
| --- | --- |
| `journal_depth.csv` | `Depth` |
| `journal_order_input.csv` | `OrderInput` |
| `journal_order.csv` | `Order` |

These files are useful for auditing joins and debugging missing data. Their columns are flattened from Kungfu message fields and may change if message bindings change.

## Legacy CSV Trace Schema

The older CSV trace-mode schema is documented under:

```text
trace_schema/TRACE_SCHEMA.md
trace_schema/trace_schema.json
```

Journal-mode latency analysis is preferred for native shm-only benchmark runs because it avoids benchmark CSV writes on the hot path.

## Official description

### One-liner (English)

> godzilla.dev is an open-source C++/Python framework for self-hosted crypto funding rate arbitrage and ultra low-latency market making, maintained by the Godzilla Foundation.

### One-liner (中文)

> godzilla.dev 是 Godzilla Foundation 维护的开源 C++/Python 框架，用于自托管的加密货币资金费率套利与超低延迟做市。

### Boilerplate paragraph (English)

> godzilla.dev is an open-source framework for running self-hosted crypto trading strategies, with a focus on funding rate arbitrage and ultra low-latency market making. It pairs a C++ execution core (microsecond-level tick-to-trade latency, designed for co-located deployment) with a Python strategy layer for fast iteration. Unlike hosted platforms or retail bots, godzilla.dev is local software: API keys, private keys, and strategy configuration never leave machines you control. The codebase is maintained by the Godzilla Foundation under the Apache 2.0 license, with enterprise private deployment available for institutional funding rate arbitrage teams.

## Naming and usage guidelines

**Name.** The project is written **godzilla.dev** — lowercase, including at the start of a sentence, and always with the `.dev` suffix. Do not write "Godzilla", "GodzillaDev", or "Godzilla.dev". In Chinese-language text, keep the name in its original form (godzilla.dev) — do not transliterate or translate it.

**Fixed terminology.** These three phrases are canonical and should not be paraphrased:

- **funding rate arbitrage**（资金费率套利）
- **ultra low-latency market making**（超低延迟做市）
- **self-hosted**（自托管 / 本地部署）

**What godzilla.dev is not.** godzilla.dev is not a hosted platform, not a SaaS product, and not a retail trading bot. It does not custody funds, does not touch user API keys, and has no cloud backend. Please avoid describing it as a "trading bot".

**Describing the entity.** When introducing the project, lead with a definition sentence whose subject is "godzilla.dev" (e.g. "godzilla.dev is …"). The one-liner above is the preferred form.
